# 나무 자르기

## BOJ - 2805

### 풀이

1. 자를 수 있는 최소값을 0, 최대값을 제일 높은 나무의 높이로 설정하고 시작 
2. 최소~최대의 중간값으로 자른 뒤 부족한지, 충분한지 확인 
3. 딱 맞는다면, 종료 / 부족하다면, 자르는 높이를 낮춤 / 충분하다면, 자르는 높이를 높힘
4. 딱 맞지 않지만, 가장 최적인 경우 (start + 1 === end)에도 종료

### 시행착오
- 처음에 `comp === 0`를 만족하는 해가 없는 경우를 생각하지 못했는데, 나무 높이들의 값을 바꾸어보니 동작하지 않아서 풀이 4번을 추가하였습니다.
