# 프로그래머스 - 12977
### 풀이
- 배열 전체에서 3개의 수를 순서상관없이 뽑으면 됨
- 모든 경우의 수를 찾으려면, 앞에서부터 하나씩 뽑고, 뽑아야 할 갯수가 부족할때 그만두면 됨
- picks 배열에 수 3개가 모였으면, 소수인지 판단하고, 맞다면 1, 아니라면 0을 반환함 
- 반환한 모든 값을 더하면 소수의 갯수가 됨

### 시행착오 
-  `PICK_AMOUT - picks.length <= nums.length - idx` 조건문을 도출하는 부분이 헷갈렸습니다.
	- 의미는 `앞으로 뽑아야 할 갯수 <= 뽑을 수 있는 갯수` 입니다.
