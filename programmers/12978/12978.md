# 프로그래머스 - 12978
### 풀이
- 도로마다 소요시간이 다르므로 다익스트라 알고리즘 사용
- 다익스트라를 사용해서, 1번마을에서 출발한 뒤 모든 마을 까지의 최단 거리를 구하면 됨. 
- 최소힙 구현을 위해 우선순위 큐를 사용함
- 최소힙을 이용해 거리를 짧은 순으로 꺼냄
- 현재 마을에서 다음 마을로 이동했을 때 더 짧을 거리라면 distances[next] 값을 갱신
- 마지막으로 distance배열에서 값이 K 이하인 마을의 개수를 세면 됨.   

### 시행착오 
- 처음에 JS로 만드려고 했으나, 최소힙 구현을 매번 할 자신이 없어 JAVA로 선회하였습니다.
